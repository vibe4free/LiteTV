📺 LiteTV 配置

M3U 播放列表

输入 M3U 播放列表的完整 URL，例如: http://example.com/playlist.m3u
订阅链接常把同一频道按不同源重复列出；开启后合并为一个频道并依次尝试各个源（播放界面按 R 或双击可手动切换源）。列表本身没有重复时无任何影响。

EPG 电子节目单

支持 {name} 和 {date} 占位符，例如: http://epg.example.com/api/diyp?ch={name}&date={date}

播放与显示

播放设置需重启电视端应用后生效；显示设置下次打开频道列表时生效。

关于 / 更新

「立即更新」会让电视自动下载并校验安装包，然后在电视上弹出系统安装确认——安装需要有人在电视旁按确认。
